# 🤖 CV-Agent (Resume Analyzer & Evaluator)

A Python-based web application built with **Streamlit** to parse, evaluate, and analyze resumes and candidate strengths.

---

### 🚀 Features
* **PDF Resume Parsing:** Extracts text and information from candidate resumes.
* **Candidate Evaluation:** Analyzes strengths and matches candidate skills with job requirements.
* **Interactive UI:** Built with Streamlit for a seamless user experience.

---

### 🛠️ Tech Stack
* **Python**
* **Streamlit**

---

### ⚙️ How to Setup & Run

1. **Open the Project in VS Code:**
   * Open **Visual Studio Code**, select **File > Open Folder**, and choose this project's folder.
   * Open the integrated terminal (`Ctrl + ~`).

2. **Get & Add your API Key:**
   * Get your Google Gemini API Key directly from [Google AI Studio](https://aistudio.google.com/).
   * Place your API Key into the designated variable inside `app_web.py` (or set it up in your Streamlit secrets).

3. **Run the Application:**
   * Execute the following command in your VS Code terminal to start the app:
   ```bash
   streamlit run app_web.py
